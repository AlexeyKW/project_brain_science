# H-001: NDVI отрицательно связан с LST внутри городской застройки лета 2024

## Формулировка (зафиксирована 2026-11-02, до просмотра данных)

После контроля доли застройки в аналитической единице NDVI отрицательно
ассоциирован с LST: увеличение NDVI на 0.1 сопровождается снижением LST.

## Метрика и критерий успеха

- Метрика: β_NDVI в линейной модели LST ~ NDVI + built_fraction (+ co-variates), оценённой блочной spatial-CV (D-014).
- Критерий успеха: β_NDVI < 0 с 95% ДИ, не включающим 0; R²_oob ≥ 0.35.
- Критерий опровержения: 95% ДИ β_NDVI включает 0.

## План анализа (предрегистрация)

1. Аналитическая единица: квартал (OSM-полигоны), агрегаты NDVI/LST средние, n ожидается ≥ 10 000.
2. Модель: OLS с HC3-ошибками внутри блоков; бутстрэп по блокам для ДИ.
3. Чувствительность: (a) пиксельный vs квартальный уровень; (b) сцены июнь–август vs весь сезон.
4. Multiplicity: серия из 3 сравнений, коррекция Holm (X-04).

Пайплайн: данные → препроцессинг → модель → фигура. Каждый узел — src-модуль + датакарта.

```
DS-001 Sentinel-3 SLSTR LST (Казань, 2024)      DS-002 OSM dump 2024-06-15 (застройка)
        │                                              │
        └───────────► src/preprocess/align.py ◄────────┘
                  (репроекция в equal-area, ресемплинг 300 m,
                   маска воды/облаков, zonal stats по кварталам)
                              │
                              ▼
                 data/processed/analysis_grid.parquet
                              │
                              ▼
                 src/models/spatial_cv.py  (D-014: блоки по пространственным кластерам)
                              │  seed 42, срезы E-020…E-024
                              ▼
                 results/fig3_ndvi_lst.png ◄── EXPERIMENTS/E-023.yaml
                              │
                              ▼
                 CLAIMS/C-007 ──► paper/sections/results.md#L42 (якорь {{claim:C-007}})
```

## Границы ответственности

| Модуль | Отвечает за | Не отвечает за |
|---|---|---|
| `src/preprocess/align.py` | выравнивание сеток, CRS (X-06), маски | содержательный анализ |
| `src/models/spatial_cv.py` | блочные срезы, seed, отчёт метрик | интерпретацию β |
| `src/reproduce.py` | smoke-перезапуск по E-*.yaml, сверка хешей | полный прогон (CI-full) |
| `src/validate_brain.py` | схемы, уникальность ID, целостность графа | семантику текстов |

## Известные дефекты пайплайна

- LST SLSTR ночные сцены пропускают центр города (облака) → смещение выборки, см. DS-001 §дефекты.
- OSM полнота зданий неоднородна по районам → контроль застройки недооценивает окраины (Critic, 2026-11-18).

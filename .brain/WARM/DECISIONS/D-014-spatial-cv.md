# D-014: Валидация моделей — только блочная spatial-CV

## Контекст

Пиксели/кварталы пространственно автокоррелированы (полураспад ~1.8 км по вариограмме LST).
Случайное разбиение даёт утечку через соседние наблюдения в train/test → оптимистичные метрики.

## Альтернативы

1. **Случайная K-fold** — отвергнута: F-019 показал R² = 0.81 против 0.42 у блочной; причина — утечка через соседние пиксели.
2. **Блочная CV (leave-location-out по пространственным кластерам)** — выбрана: 5 блоков, кластеризация k-means по координатам (EPSG:3576), k = 40 кластеров → блоки.
3. **Буферная CV (leave-one-out с буфером исключения)** — отложена: в 3× дороже по вычислениям; вернёмся при финальной оценке для рукописи.

## Выбор и последствия

- Все метрики проекта с E-021 считаются только блочной CV; seed = 42, фиксация блоков в `src/models/spatial_cv.py`.
- Метрики до E-021 (E-018, E-019) недействительны, связанные claim C-004…C-006 → `retracted`.
- Стоимость: дисперсия оценки выше; компенсируем бутстрэпом по блокам (см. H-001 план анализа).

## Что изменит решение

Появление DS-003 (высота застройки) с пространственным паттерном, ломающим кластеризацию (проверка Critic'ом).
